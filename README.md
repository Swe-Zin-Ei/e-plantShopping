# e-plantShopping

## Overview

**e-plantShopping** is a React-based shopping cart application for purchasing plants online. Users can browse a variety of plants, add them to a cart, and manage quantities.

## Features

- Browse a catalogue of plants
- Add plants to the shopping cart
- Increase or decrease item quantities
- View total cart cost
- Responsive and user-friendly interface

## Tech Stack

- React
- Redux Toolkit
- Vite
- CSS
